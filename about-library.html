About

The Library

The Ergodicity Library is a Python-based open-source library focused on the study of stochastic processes, ergodicity, and time-average behaviors. Initially inspired by the work of Ole Peters and Alexander Adamou in Ergodicity Economics, the library extends far beyond economics and can be applied in fields such as biology, physics, finance, and more.

Architecture

Three core modules

The library is organized into three interconnected modules, each providing specialized functionality for different aspects of stochastic analysis.

Module 01

Processes

Core stochastic dynamics — define, simulate, and analyze a vast catalog of stochastic processes with full parameter control.

basic.py multiplicative.py with_memory.py increments.py lib.py constructor.py custom_classes.py default_values.py definitions.py discrete.py
Module 02

Tools

Computational functions for solving, fitting, and evaluating stochastic models with symbolic and numerical methods.

compute.py evaluate.py fit.py solve.py multiprocessing.py automate.py preasymptotics.py research.py partial_sde.py helper.py
Module 03

Agents

AI training systems — create artificial agents that learn optimal behavior under uncertainty through evolutionary and neural approaches.

agents.py agent_pool.py evaluation.py evolutionary_nn.py sml.py portfolio.py probability_weighting.py
Features

Key capabilities

Designed to be powerful yet easy to use, the library simplifies the management of stochastic processes and ergodicity economics calculations.

⚡

Custom Configurations & Multiprocessing

Flexible parameter control and parallel computation across all available CPU cores.

◐

Advanced Visualizations

3D interactive graphs, animated trajectories, and publication-ready plots.

⟳

Research Automatization

Automated research pipelines and reporting for reproducible analysis.

∫

NumPy, SciPy, SymPy, Matplotlib, TensorFlow

Deep integration with the Python scientific computing ecosystem.

∂

Itô and Non-Itô Processes

Support for both standard and non-standard stochastic calculus frameworks.

∑

Symbolic Computation

Powerful symbolic stochastic calculus with automated SDE solving.

Get Started

Installation

Both the library and the accompanying tutorial book are free and open-source and can be installed with a single line of code.

From PyPI

Quick Install

$ pip install ergodicity-library
From GitHub

Clone & Install

$ git clone https://github.com/
  Kendiukhov/ergodicity_library.git
$ pip install -r requirements.txt
