Ergodicity Library: An Introduction

A comprehensive guide and tutorial book for the Ergodicity Library. It is mostly a tutorial on how to use the library, providing many use cases across different disciplines including economics, physics, biology, and chemistry.

Accessible for absolute beginners while containing interesting and advanced content for experienced Python users and experts in ergodicity economics and stochastic analysis.

# Install the tutorial book
$ pip install ergodicity-library

Before You Start

Prerequisites

What you should know before diving into the Ergodicity Library.

⟨/⟩ Programming

  • Python basics (variables, functions, classes)
  • NumPy array operations and broadcasting
  • SymPy symbolic computation fundamentals
  • Matplotlib plotting and visualization
  • Optional: TensorFlow / Keras for agent training

∫ Academic Background

  • Probability theory and random variables
  • Itô calculus and stochastic integration
  • Stochastic differential equations (SDEs)
  • Statistical estimation methods
  • Basics of ergodic theory (helpful but not required)
